# 📊 TechZone - Admin Dashboard

Um painel administrativo moderno, responsivo e interativo criado para gerenciamento de estoque, vendas e relatórios de e-commerce.

---

## 🌟 Sobre o Projeto

Este projeto consiste em um dashboard administrativo desenvolvido com tecnologias web fundamentais (HTML, CSS e JavaScript). 

O layout base foi construído com referência ao tutorial de [Bob's Programming Academy](https://youtu.be/ewN4_mcaI84), recebendo diversas **melhorias, personalizações visuais e novas funcionalidades**:

- 🌓 **Suporte a Dark / Light Mode**: Alternância dinâmica de tema através de um botão customizado no header com persistência de dados.
- 🎨 **Paleta de Cores & Design**: Identidade visual reformulada utilizando variáveis CSS para fácil manutenção.
- 🔤 **Nova Tipografia**: Integração da fonte *Poppins* via Google Fonts para melhor legibilidade.
- 📱 **Totalmente Responsivo**: Adaptação para dispositivos móveis, tablets e desktops utilizando CSS Grid e Media Queries.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da aplicação.
- **CSS3**:
  - CSS Grid & Flexbox para layouts.
  - Variáveis CSS (Custom Properties) para gerenciamento de temas.
  - Media Queries para responsividade.
- **JavaScript (Vanilla)**:
  - Manipulação da DOM para alternância do tema e abertura do menu lateral.
- **Libraries & Recursos Externos**:
  - [ApexCharts](https://apexcharts.com/): Gráficos interativos (Barras e Área).
  - [Google Fonts](https://fonts.google.com/): Família de fontes *Poppins*.
  - [Material Icons Outlined](https://fonts.google.com/icons): Ícones do header, menu e cards de métricas.

---

## ⚡ Funcionalidades

- [x] **Cards Informativos**: Exibição de métricas de produtos, categorias, relatórios e notificações.
- [x] **Gráficos Interativos**:
  - Gráfico de barras para top produtos mais vendidos.
  - Gráfico de área combinado para ordens de compra e venda.
- [x] **Menu Lateral (Sidebar)**: Navegação rápida com ícone colapsável em telas menores.
- [x] **Alternador de Tema**: Botão no topo para trocar entre modo claro e escuro.
